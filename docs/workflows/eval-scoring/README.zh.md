# 交接评测打分

English: [README.md](README.md)

每个模型得到一个 0–1 的分数：**总分 = 0.5 × 完成度 + 0.5 × 质量**，每个数字都带 95% 置信区间。
区间宽窄由试次数量决定：10 次试验的区间很宽，只有两个模型的区间不重叠，才能说它们真的不同。规则于 2026-10-23 和用户确认。

```bash
python docs/workflows/eval-scoring/report.py <out_prefix> <human_ref_demo_dir> <dataset_dir> ...
```

- `human_ref_demo_dir`：人类示范基准，目前是 `wwqcleverghost/v4-handover2-trimmed`。
- `dataset_dir`：评测数据集（有 `success.csv`）和/或示范数据集（只算质量）。嵌套在 `dataset/` 里的也可以。
- 输出 `<out_prefix>.csv`（每个数据集一行，所有分数和区间）和 `<out_prefix>.svg`（每个数据集一根叠加柱：
  蓝色 = 0.5 × 完成度，橙色 = 0.5 × 质量，细线 = 总分的置信区间；示范数据集的完成度画成虚线框、按 1.0 计，方便对比）。
  结果放在 `outputs/eval_scores_<date>/`，示例见 `outputs/eval_scores_20261023/`。
- 只读 `observation.state` 和 `action`，不看视频。lerobot 环境即可（不需要 matplotlib）。

## 完成度（只有评测有）

5 个阶段，由 `score.py` 根据夹爪判断（抓住 = 指令闭合、而实测位置卡在指令之上 >= 2 个单位且持续 >= 0.5 秒）：
1. 前往（reach）— 一只手臂移动超过 30 个单位并张开夹爪
2. 抓住（grasp）— 抓住胶带（允许重新抓取）
3. 交接前不掉（no drop）— 另一只手臂在第一只松手前开始抓住
4. 交接成功（handover）— 两只手同时抓住 >= 0.5 秒，然后第一只张开
5. 放好（place）— 之后第二只手臂张开

- **阶段通过率 = (通过 + 1) / (进入 + 2)**。没走到某个阶段的试次不算这个阶段失败。
  +1/+2 让样本少的阶段往 0.5 靠（1/2 变成 0.5，7/7 变成 0.89），避免一两次样本就拿到极端分数。
- 每个阶段通过率都做**截断**：<= 0.5 记 0 分，1.0 记 1 分，中间按比例换算。完成度 = 5 个截断后通过率的平均。
- `success.csv` 里的人工成功标签是最终结果（不用看视频）：标成功 → 所有阶段都通过；标失败但自动判断 5 个阶段全过 →
  "放好"记失败。自动判断和人工标签在 110 个试次中 105 个一致（2026-10-20）。
- 另外报告、但不计入分数：整体成功率（如 7/10）及 Wilson 置信区间；每个阶段的 `通过/进入 [区间]`（漏斗，看出模型卡在哪一步）。

## 质量（评测和示范数据集都有）

逐试次加权，和人类基准的中位数比较：
- **平滑（0.4）**— 运动中每秒的小幅关节来回次数（`smooth.py`：死区 0.5，摆幅 < 5）
- **速度（0.3）**— 从开始动到放下松手的用时，只算成功的试次
- **不停顿（0.3）**— 任务中站着不动（< 5 单位/s 且持续 >= 0.5 秒）的时间占比

平滑和速度：**和人类中位数一样或更好记 1 分，差 2 倍记 0.5 分，差 4 倍记 0 分**（每差一倍扣一半）。
不停顿 = 1 − 停顿占比，和阶段通过率一样截断。人类示范自己大约 0.9 分（一半示范比它们自己的中位数差），
这个分数不能和其他项目的数字直接比较。

## 不确定性

阶段通过率和成功率：Wilson 95% 置信区间。完成度、质量、总分：按试次自助抽样（2000 次，取 2.5–97.5 百分位）。
10 次试验分不出 7/10 和 4/10（Fisher p ≈ 0.37）；区间重叠时要说明，宁可给前几名模型多测几次，也不要把打分做得更细。
