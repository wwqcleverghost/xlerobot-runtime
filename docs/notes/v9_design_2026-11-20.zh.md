# v9 设计：调研、证据和预先写下的预期（2026-11-20）

English: [v9_design_2026-11-20.md](v9_design_2026-11-20.md) · 怎么跑：[`docs/workflows/v9/`](../workflows/v9/README.zh.md)

## 1. 为什么写这份文档

第一批进度回喂模型（progdelta / progself / deltainc）的失败，其实在训练前就能测出来：输入的进度 s 用图像就能推出来（阶段识别 0.92），
所以策略不看它（2026-11-16：s 平移 ±2 个阶段，关节只变 0.1–0.6°，不超过换一次噪声）。当时花了几十次实机评测才发现。

所以 v9 只有一条规矩：**一个条件信号要过三关才上实机。**

1. **信息关**（训练前）：信号不能被模型已经看到的东西（图像 + 关节）推出来。推得出来，模型不用这个输入也能拿到同样的信息，就会忽略它。
2. **数据关**（训练前）：训练集里要有"同类状态、不同信号、不同动作"的样本。没有的话，信号和动作之间没有任何联系可学。
3. **干预关**（训练中 / 后，`examples/xlerobot/gate_v9.py`）：同一观测、同一噪声，只改信号——动作的变化要明显大于换噪声，方向还要对。

第 5 节在**任何结果出来之前**写下每个模型的预期。结果出来后拿它对照，预期不事后修改。

## 2. 证据（本会话实测）

| 问题 | 结果 | 结论 |
|---|---|---|
| 动作跟不跟进度输入走？（11-16） | 变化 ≤ 换噪声 | 第一批和基线打平的原因 |
| 在模型**自己**卡住的帧上，32 次采样里合上 A 夹爪的比例 | 基线 0.027、progdelta 0.090、progself 0.004；别的模型在同样的帧上最高 0.383 | 同一模型重采样很难逃出来；必须改变它在这些状态学到的东西 |
| 54 个留出试次的卡住帧（参照） | 合爪比例：基线 0.112、progdelta 0.061、progself 0.070；进度误差 0.28–0.30 阶段；增益 AUC 0.65–0.69 | v9 要超过的数字 |
| 好 / 坏（优势）能否从观测推出？（kNN，按试次留一，A对位 + A抓住） | 关节 AUC 0.66；图像特征（v6 编码器）0.74；两者 0.74；53–58% 的"坏"帧附近有 ≥30%"好"帧 | **过信息关**：和进度（0.92）不同，这个指示带有观测里没有的信息 |
| 后退 vs 前往能否从观测分出？ | 只看位置 0.47；加 1 帧速度 0.61 | **过信息关**：只有指示能说明往哪走 |
| 卡住后恢复的样本有多少？ | A对位 / A抓住 停 ≥2 秒后又动起来 22 次；之后抓到的 8 次。示范里静止 ≥1 秒的只有 83 帧 | **"停顿时长"输入过不了数据关**：8 个例子教不会"停久了怎么办"。它留在模型外（StallGuard），先用 `STALL=ask` 收集恢复数据 |

kNN 的可推程度是下限，训练出来的网络可能推得更好；所以干预关检验的是训练好的模型本身。

## 3. 相关工作：做了什么、证据多强、我们拿什么、什么情况下会失效

**以优势为条件的策略。**
- *π\*0.6 / RECAP*（Physical Intelligence，[arXiv 2511.14759](https://arxiv.org/abs/2511.14759)）：VLA 以二值优势指示为条件（阈值 = 每个任务价值的
  30% 分位数），用示范、自主试次和人工纠正训练；指示随机丢弃，从而能用无分类器引导。证据：实机大幅提升，但价值函数由 VLM 初始化，数据量远大于
  我们的 58 条示范 + 216 个试次。*我们拿*：二值指示、30% 阈值、失败当"坏"混进来。*价值的替代*：1 秒内涨的进度。
- *CFGRL*（Frans 等，[arXiv 2505.23458](https://arxiv.org/abs/2505.23458)）：条件策略和无条件策略之间的引导就是一步策略改进；权重加大会更好，
  到某一点后发散。证据：离线 RL 基准（仿真）。*我们拿*：推理时可调的引导权重 w，离线扫 1 / 1.5 / 2 / 3。
- *以回报为条件的监督学习何时有效*（Brandfonbrener 等，[arXiv 2206.01079](https://arxiv.org/abs/2206.01079)）：以结果为条件只有在很强的假设下
  才能恢复好的行为（动力学接近确定、关键状态上覆盖了好动作）；它造不出数据里没有的行为。*结论*：引导只能挑出卡住状态附近**已有**的合爪动作；
  那里没有的话，w > 1 只是外推。所以 G1 还要检查"好"比"坏"合爪更多。

**从失败中学，但不模仿失败。**
- *AFIL*（[arXiv 2605.08434](https://arxiv.org/abs/2605.08434)）：同一骨干上一个成功、一个失败的动作生成器，采样时推离失败的那个。
  *CCDP*（[arXiv 2503.15386](https://arxiv.org/abs/2503.15386)）：推理时避开之前失败过的采样。*RedFlow*（[arXiv 2607.27782](https://arxiv.org/abs/2607.27782)）：
  按估计进度 + 本体感受把相似状态下执行过的动作块分组、打分，把差的往好的方向拉（离线，三个实机任务 56.7% → 74.7%）。
  *我们拿*：失败当负面证据（`adv`），你的屏蔽方案（`negmask`），以及 RedFlow 那种按相似状态分组的思路（进度标签用最近的示范帧）。
- flow matching 的局限（我们发现的）：关节和进度一起去噪，被屏蔽帧的带噪关节仍然进入网络输入。屏蔽去掉的是关节的**学习目标**，不是失败动作的全部影响。

**从视频得到进度 / 奖励。**
- *SARM / RA-BC*（[arXiv 2509.25358](https://arxiv.org/abs/2509.25358)）：分阶段的进度，再按进度增益给样本加权。它的提升来自又大又脏的数据；
  在我们 58 条精选示范上，v6 的 RA-BC 和基线打平。*我们拿*：RA-BC，但用诚实的、随时间衰减的进度，并用在有慢段和停顿的评测试次上。
- *ReWiND*（[arXiv 2505.10911](https://arxiv.org/abs/2505.10911)）：把成功视频倒放，让奖励模型学会进度可以下降。*我们拿*：倒放，但用于策略（后退 episode），
  且只倒放空中的前往段（手里没有胶带，倒放的运动物理上成立）。
- *GVL*（[arXiv 2411.04549](https://arxiv.org/abs/2411.04549)）：用 VLM 估进度；它的"价值与时间顺序相关性"可以拿来检查任何进度估计器。

**发现卡住并恢复。**
- *Sentinel*（[arXiv 2410.04640](https://arxiv.org/abs/2410.04640)）：把失败分成"动作乱"和"笃定地不推进"——我们的是后一种。
  *Rewind-IL*（[arXiv 2604.16683](https://arxiv.org/abs/2604.16683)）：用前后动作块不一致来判失败，然后把机器人送回检查点状态。*FIPER*、*FAIL-Detect*：
  运行时失败预测。*我们拿*：能实时计算的卡住判据（关节 N 秒在 3° 盒内、自己的进度不涨），以及三种应对：重采样、脚本倒退、学出来的后退。
- *RaC*（[arXiv 2509.07953](https://arxiv.org/abs/2509.07953)）：人工接管时先恢复、再纠正；长任务上比普通示范省约 10 倍数据。
  *HG-DAgger*（[arXiv 1810.02890](https://arxiv.org/abs/1810.02890)）/ *ThriftyDAgger*：由人、或由机器人按自己估计的风险决定何时接管。
  *我们拿*：`STALL=ask`，卡住时机器人请求接管，录下数据里缺的恢复片段（目前只有 8 个）。

**在多个采样里挑。**
- *V-GPS*（[arXiv 2410.13816](https://arxiv.org/abs/2410.13816)）、*RoboMonkey*（[arXiv 2506.17811](https://arxiv.org/abs/2506.17811)）：采多个动作，用学到的
  验证器排序。*我们拿*：策略自己预测的进度当便宜的验证器（`best_of_n`）；上限取决于卡住状态下好样本的比例（第 2 节）。

**输入为什么会被忽略。**
- *Copycat agents*（Wen 等，[arXiv 2010.14876](https://arxiv.org/abs/2010.14876)）和因果混淆（de Haan 等 2019）：策略会用最省事的输入；和其他信息重复的
  输入会被丢掉或被照抄。这就是第一批的机制，也是第 2 节先测"可推程度"的原因。

## 4. 设计（你的想法 → v9 的组成）

| 你的想法 | v9 中的部分 | 信息 / 数据 | 验收 |
|---|---|---|---|
| 进度隐式，不做输入 | 进度只预测（动作后 9 维） | — | G4、G5 |
| 更好的进度，卡住不涨 | 诚实进度：最近示范帧的路程进度 | — | G4（增益 AUC ≥ 0.75） |
| 重标评测试次，停越久进度越降，再 RA-BC | `rabc` 用时间衰减进度（静止时每秒降 0.3 阶段） | 数据过（停越久好标签越少，48% → 6%） | 离线排名 |
| 学失败的进度、不学失败的动作 | `negmask` | — | G3 |
| 进度正负控制动作 | `adv` 好 / 坏指示 + 引导 | 过 / 过（AUC 0.74，同处标签混合） | G1 |
| 监督者：卡住就退回去重新对位 | `advback`（学出来）、`STALL=rewind`（脚本）、`STALL=learned` | 过 / 过（AUC 0.47，58 段） | G2 |
| 增量变化回喂（停顿时长） | 不进模型（只有 8 个恢复）；先用 `STALL=ask` 收集恢复数据 | 数据不过 | 之后 |
| 重采样能过去 | `best_of_n`，按自己的进度挑 | — | G5 |

## 5. 预先写下的预期（在任何 v9 结果之前）

| 模型 | 预期 | 什么结果会推翻它 |
|---|---|---|
| `prog` | 卡住帧合爪比例 0.10–0.20（比 v6 覆盖更多卡住状态）；G5 通过（相关 ≤ −0.2） | 合爪比例低于 v6 基线的 0.112 |
| `adv` | G1 在 w = 1 或 2 通过，效果 / 噪声 3–10；合爪(好) − 合爪(坏) ≈ 0.1–0.3 | 效果 / 噪声 < 3：指示像第一批的进度一样被忽略 → 60K 时停掉 |
| `adv_r2` | 离线数字与 `adv` 相差 ±0.03 以内 | 差得更多：模型之间小于这个差距的离线差别都是噪声 |
| `negmask` | 留出失败帧上的进度误差低于 `prog`；合爪比例 ≈ `prog` | 进度比 `prog` 还差：屏蔽带来的坏处大于收获 |
| `rabc` | 合爪比例 ≈ `prog` ± 0.03；闭环里长停顿更少（只能实机看） | —（预期较弱；之前的 RA-BC 打平） |
| `advback` | G2 通过：≥ 70% 的采样里"后退"让 A 臂朝起始姿态移动 | 朝向比例 < 0.7 或效果 / 噪声 < 3 |

实机统计：30 次试验的成功率误差约 ±17 个百分点，所以实机比较看 A对位 的抓取率，并配对胶带位置；只有过了验收的模型才上实机。
